# 公会 · 称号 · 排行榜 · 灰烬中的联结

>一个人的行走终会疲惫，可当掌心印记相同的人聚到一起，废土上便升起了第四种可能。幸存者联盟从来不是自上而下的册封，而是足迹重叠处自然生长之物——公会是它的骨架，称号是它的勋章，而排行榜，则记下了谁在这个被冻结的时代里走得最远。

除了单人养成，回声宇宙也为行者们准备了完整的**社交与荣誉体系**。

## 公会系统

行者可以创建或加入公会，与同伴共享这个破碎世界的重量。公会提供丰富的模块：

- <font color="#FFD306">公会银行 / 仓库</font>：共享资金与装备
- <font color="#B7FF4A">签到 / 活动 / 任务</font>：日常与公会目标
- <font color="#FF4A4A">公会战（KitPvP）</font>：公会间的对抗，结束后自动送回赛前位置
- <font color="#CC66FF">圣石 / 公会称号</font>：公会的专属成长与身份
- <font color="#2894FF">专属公会世界</font>：公会自己的天地
- 公告、Logo 商店、权限管理等

> 未加入任何公会的行者，默认显示为 <font color="#FF4A4A">闲散</font>。找主城 NPC「公会助手」即可进入公会菜单。

## 称号系统

称号是行者身份与实力的直观展示，可通过**商店购买、合成、套装**等方式获取，部分传说称号还附带可观的属性加成：

| 称号 | 品质 | 效果 |
|------|------|------|
| <font color="#FFFFFF">初来乍到</font> | 默认 | 新行者的起点 |
| <font color="#FFDD00">云雷之师</font> | 传说 | 物理 / PVP / PVE 伤害、暴击、生命等多项加成，附带力量 / 抗性药水 |
| <font color="#CC66FF">魔法之主</font> | 传说 | 雷击 / 冰冻 / 燃烧等元素属性，附带专属粒子特效 |

称号系统还包含称号商店、合成、套装组合与自定义称号等玩法。

## 排行榜

回声宇宙实时统计多项排行，激励行者们你追我赶：

- <font color="#FF4A4A">AP 战力排行榜</font>：综合战力的比拼，养成成果的终极体现
- <font color="#FFD306">金币排行榜</font> · <font color="#2894FF">钻石排行榜</font>：财富的较量
- <font color="#CC66FF">周 / 月 / 年 / 总累充排行榜</font>：支持者的荣誉

各排行榜均设有对应的**排名奖励**，登顶不只是荣耀，也是实打实的回报。

## 属于你的篇章

>"三足踏于废土之上，各执一词，各怀其刃。唯行者无冕无座，以脚步为疆，以呼吸为誓。"

公会、称号、排行榜——它们记录的从来不是神的意志，而是行者自己书写的故事。诸神已经讲完了他们的篇章，剩下的，由行走在这片废墟之上的你来续写。
