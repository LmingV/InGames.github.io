# 副本与竞技场 · 试炼之门

>浮空神冢的彩虹桥残段仍指向那些未熄的试炼，英魂在风里重播着永不落幕的战斗。行者踏入副本的那一刻，便是接过了一场亘古的邀约——用刀锋回答神冢的低语，用鲜血兑换神格的碎屑。倒下三次，你会被送回门外；但只要还站着，奖励袋里就装着离神兵更近的一步。

回声宇宙的副本由 **CoreArena** 驱动，是一种**波次打怪竞技场**：进入后迎战一波波怪物，撑到最后即可通关领取奖励。

## 六大副本

服务器现开放 **6 个主题副本**，每个副本对应一个专属奖励袋：

| 副本 | 对应奖励袋 |
|------|-----------|
| <font color="#2894FF">冰霜副本</font> | 冰霜奖励袋 |
| <font color="#FFFFFF">剔骨副本</font> | 剔骨奖励袋 |
| <font color="#FF9000">拳击副本</font> | 拳击奖励袋 |
| <font color="#FFDD00">旺仔副本</font> | 旺仔奖励袋 |
| <font color="#FF4A4A">红沙副本</font> | 红沙奖励袋 |
| <font color="#B7FF4A">风蚀副本</font> | 风蚀奖励袋 |

通关对应副本，即可获得同名奖励袋，开出该副本的专属产出。

## 副本规则

- **生命次数**：每场副本有 3 次死亡机会，用尽即失败退出
- **职业 / 等级门槛**：部分副本对进入者有等级要求
- **自带装备**：部分副本允许使用你自己的装备迎战
- **入场**：新手副本需要「入门凭证」（末影珍珠）等入场道具；部分副本需先通过 NPC「常驻活动」解锁

## BOSS 与宝藏

副本与野外的强敌中，潜伏着一批有名有姓的 BOSS——王五、迈克、安格斯、旺财、玛丽、凯莉、锤石、博丽、艾莎、阿努比斯、咯咯鸡、安琪、杰克、膨膨…… 击败它们可获得**对应的宝藏箱**，开出装备与珍稀材料。

每位 BOSS 还关联着一套**主题道具与伪装**，例如：

- <font color="#FFFFFF">安格斯的剔骨刺</font>（石剑，物伤 +10 / 暴击 +10 / 暴伤 +20，带突进）
- <font color="#B7FF4A">玛丽的风蚀弓</font>（弓，物伤 +10 / 移速 +15%，箭雨技能）
- <font color="#FF4A4A">锤石的魂引之灯</font>、<font color="#FFDD00">咯咯鸡的GC盾</font>（双倍收发伤害）、阿努比斯的枯萎……

> BOSS 图鉴的完整名录与数值，见《怪物与BOSS图鉴》。

## 新手引导

初入回声宇宙的行者，可从「新手教程」商店（"欢迎来到回声宇宙"）与新手副本起步，用「入门凭证」踏入第一场试炼，在低门槛的战斗中熟悉淬炼、宝石与副本机制，再逐步挑战六大主题副本。
