# 抽奖箱 · 神格的赌注

>神格碎片从不平均地馈赠。有人凿开一箱只得一捧尘埃，有人却在开启的刹那迎来满室金光。抽奖箱是这个破碎世界最诚实的隐喻——你永远不知道下一箱藏着通往传说的钥匙，还是又一次擦肩而过。

回声宇宙的抽奖箱由 **ExcellentCrates** 驱动，共 **32 个箱子 + 15 把钥匙**。每把钥匙对应一个奖池，用对应钥匙开启对应箱子，即可抽取其中产出。

## 钥匙与获取

15 把钥匙覆盖上述各奖池（普通 / 中等 / 高等 / 完美淬炼钥匙、各档宝石箱钥匙、普通 / 高级开槽钥匙、农牧箱钥匙、金粒箱钥匙等）。其中三把可作为独立道具直接持有：

- <font color="#FFD306">属性淬炼</font>（钥匙）→ 开启属性淬炼奖池
- <font color="#CC66FF">高级宝石抽奖箱钥匙</font> → 开启高级宝石奖池
- <font color="#FFFFFF">高级开槽钥匙</font> → 开启高级开槽奖池

它们正是**淬炼词条、宝石、开槽**三大养成线的付费 / 活动获取入口。

## 开箱体验

抽奖箱配有多种开箱动画（转轮、CSGO 式滚动、神秘箱、风暴等），开启的过程本身就是一场小小的仪式——愿神格的碎屑，垂青于你。
