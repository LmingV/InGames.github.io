# 宝石与开槽 · 镶嵌星辉

>诸神碎灭时，神格化作星雨坠落，其中最凝练的那些结晶成了宝石。它们是神性的残片，冰冷而固执，唯有先在装备上凿开容纳它们的孔隙，才肯将力量交付于人。开槽是邀请，镶嵌是契约——把一枚青鳞石嵌进剑身的那一刻，你便与一缕远古的神辉达成了交易。

宝石是装备属性的第二源泉。回声宇宙中并行着**两套宝石体系**：<font color="#FFD306">淬炼镶嵌</font>（MoeCuiLianPlus，背包点击式，最常用）与 <font color="#2894FF">符文镶嵌台</font>（MagicGem，工作台式）。

## <font color="#FFD306">开槽：先凿孔，再镶石</font>

装备默认没有宝石槽，必须先用**开槽粉**凿开：

- 使用开槽粉，有 **50% 成功率** 为装备开出一个「空宝石槽位」
- 一件装备**最多开 5 个槽**
- 开出的槽位**不可拆除**，属于装备的永久属性

开槽成功后，装备 Lore 的 <font color="#FF95CA">［宝石］</font> 段就会出现空槽，等待镶入宝石。

## 六系属性宝石

淬炼镶嵌体系的核心是**六大宝石系列**，每系分 **5 个等级**，等级越高属性越强、品质越高（普通 → 稀有 → 精良 →…→ 传说）：

| 系列 | 适用 | 属性 | 满级数值 |
|------|------|------|----------|
| <font color="#2894FF">青鳞石</font> | 武器 | 物理伤害 | 最高约 +200 |
| <font color="#FFFFFF">水夕石</font> | 护甲 | 护甲值 | 最高约 +80 |
| <font color="#FFDD00">洛凤石</font> | 武器 | 燃烧强度 | 最高约 +10% |
| <font color="#FF4A4A">赤鳞玉</font> | 武器 | 暴击强度 | 最高约 +10% |
| <font color="#B7FF4A">天星砂</font> | 武器 | 雷击强度 | 最高约 +10% |
| <font color="#CC66FF">青鸾石</font> | 护甲 | 暴击抗性 | 逐级递增 |

### 镶嵌与升级规则

- 宝石只能镶在**已开槽**的装备上
- 镶高级宝石前，需**先镶好前一级**（逐级镶嵌）
- **合成升级**：低一级的宝石集齐 **5 个**，可合成 1 个高一级的宝石

也就是说，想要一颗满级青鳞石，你得从最底层的宝石开始，一层层合成上来——这是一条不亚于淬炼的长线投入。

## 功能型宝石

除了纯属性宝石，还有一些特殊功能宝石：

- <font color="#FFDD00">点石成金宝石</font>：将石头转化为金锭（1 石头 → 64 金锭）
- <font color="#FF9000">永恒宝石</font>：使装备永不损坏（约 30% 成功率）
- 以及耐久宝石、符文类宝石等

## 宝石相关材料

- <font color="#FFFFFF">宝石粉</font>（粗糙 / 瑕疵 / 优质 / 无瑕 / 完美 混合石）：开槽与合成所需的分级材料
- 宝石可通过 <font color="#B7FF4A">宝石拆卸台</font> 从装备上取下
- 各档宝石、开槽资格也可通过**抽奖箱**开出（粗糙 / 瑕疵 / 无瑕 / 优质 / 完美 宝石箱，普通 / 高级开槽箱，详见《抽奖箱》）

## <font color="#2894FF">符文镶嵌台（MagicGem）</font>

另一套并行体系，通过专用工作台 GUI 操作：

- **符文镶嵌台**：按颜色槽位镶入符文——左蓝、右红、中绿、技能黄
- **AttributeGem**：修改原版 Minecraft 属性（生命、移速、攻击伤害、攻速、幸运、护甲、韧性、击退抗性等），分普通 / 传说 / 史诗三品质，附带成功率
- **LoreGem（符文）**：红 / 蓝 / 绿三色符文系列，每系 5 级（强攻、致命、灾祸、坚守、重盾、烈焰…）
- 还有药水宝石（发光 / 防火 / 夜视 / 隐身 / 抗性提升 / 跳跃等）、附魔宝石、技能宝石等

> 两套体系可以并存。淬炼镶嵌（六系宝石）走的是 AttributePlus 数值路线，符文镶嵌台则偏向原版属性与功能性效果——根据你的 Build 需求各取所需。
