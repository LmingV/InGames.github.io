# 装备系统 · 神造遗物的重铸

>神陨之后，凡间的铁匠炉再也锻不出旧日的神兵。可矿脉里流淌的仍是神的血液，废墟深处仍埋着未冷的锋刃。行者手中的每一件装备，都不是"造"出来的，而是从这个破碎世界里"拾"回、再一点点"养"成的。一把白铁剑，也能在千百次淬炼后，映出雷公之刃的锋芒。

回声宇宙的装备强弱，**不由材质决定，而由养成决定**。一件装备就是一张可以不断书写的画布——品质是底色，词条、宝石、淬炼则是你亲手添上的笔触。所有数值都写在装备的 Lore 上，由 AttributePlus 读取结算（详见《属性系统》）。

## 装备的品级

回声宇宙不设独立的稀有度字段，**品级直接由装备名称的颜色体现**：

- <font color="#FFFFFF">白色</font> —— 普通：全套原版材质的基础装备，养成的起点
- <font color="#FFDD00">金黄（下划线）</font> —— 传说：数值远超普通，多为顶级付费/活动套装
- <font color="#FF9000">橙金（下划线）</font> —— 神装：服务器天花板级别的稀有装备
- <font color="#CC66FF">紫色</font> —— 活动 / 特殊：节日、限定、纪念性质的独特装备

## 一件装备的构成

无论白装还是神装，Lore 都遵循同一套分段模板。看懂这五段，你就看懂了一件装备的全部潜力：

| 分段 | 含义 |
|------|------|
| <font color="#2894FF">［契约］</font> | 灵魂绑定 / 归属信息，决定这件装备属于谁 |
| <font color="#B7FF4A">［词条］</font> | 随机附加属性，由 BOSS石 / 属性石 打上 |
| <font color="#FFFFFF">［品质］</font> | 装备本体自带的固定属性 |
| <font color="#FF95CA">［宝石］</font> | 开槽与镶嵌区，显示空槽位 / 已镶宝石 / 锁定槽位 |
| <font color="#FFD306">［淬炼］</font> | 淬炼星级与进度 |

一件白板装备的这五段大多是空的——它们等待你用词条、宝石、淬炼去填满。**养成的本质，就是把这张画布填满的过程。**

## 基础装备

全套原版材质的入门装备，是每位行者最早接触的画布：

- **武器 / 工具**：剑、斧、镐、锹、锄、弓
- **防具**：皮革 / 铁 / 金 / 钻石 / 下界合金 四件套

它们自带完整的契约 / 词条 / 品质 / 宝石 / 淬炼模板，本体属性朴素（如铁剑仅 `物理伤害 +10`），但**每一格空槽、每一星淬炼位都为你敞开**。不要小看一把普通钻石镐——它同样能开槽、镶石、淬到 18 星。

## 顶级套装一览

服务器中已存在的高阶成套装备，展示了养成的天花板在哪里：

| 套装 | 定位 | 亮点属性 |
|------|------|----------|
| <font color="#FFDD00">雷公套</font> | 传说 · 雷系攻击 | 雷公之刃：物伤 +80 / 暴击 +30 / 暴伤 +60 / 雷击几率 +30 / 雷击伤害 +60 / 真伤 +60；四件防具主打生命、物防与三系抗性 |
| <font color="#FFDD00">祝融套</font> | 传说 · 火系攻击 | 祝融之刃：物伤 +120 / 暴击 +45 / 燃烧 +45；配套头盔为染色皮革（橙红 255,140,0） |
| <font color="#CC66FF">夏日套</font> | 活动 · 暑假限定 | 12 星淬炼底子、6 宝石槽 + 4 锁槽；分攻击向（雪糕棒：攻击 +25 / 暴击 +10% / 暴倍 +30%）与防御向（人字拖：生命 +20 / 防御 +10 / 移速 +20%）；由挂机池材料兑换 |

顶级套装往往预留大量宝石槽，配合高星淬炼，是行者中后期的追求目标。

## 装备从哪来

- **商店购买**：装备商店 ⚔（`equipment_shop`）、生存补给站等
- **副本掉落**：CoreArena 六大副本的通关奖励袋（详见《副本与竞技场》）
- **BOSS 宝藏**：击败 BOSS 获得对应宝藏箱，开出装备与材料
- **付费 / 活动**：累充奖励、节日限定、氪金套装等
- **系统底板**：如 SG 系列为无名底板装备，用于副本或系统发放

拿到装备只是开始。真正让它脱胎换骨的，是接下来的三条养成线——《淬炼与移星》《宝石与开槽》，以及贯穿始终的《属性系统》。
